# THE HOUSE

Мобильный браузерный 3D-хоррор.

## Исходники

Для публикации необходимо добавить `index.html` и каталог `assets/` из подготовленной сборки THE HOUSE в корень этого репозитория. Каталог `assets/` содержит GLB-модели и PBR-текстуры. Не удаляйте эти файлы при обновлениях.

## Публикация

Проект Vercel: `the-house-play`.

Этот репозиторий пока **не содержит саму игру**: после загрузки файлов требуется подключить его к существующему проекту Vercel и проверить отображение 3D-ресурсов на мобильном устройстве.
